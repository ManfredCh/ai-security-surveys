因此每个 agent run 都应有硬预算：最大 token、最大步骤、最大并发、每工具速率、总墙钟、网络与存储配额，以及明确终止条件。预算不足会降低正常效用，预算无限则把一次注入变成长期搜索；评测必须把这个权衡显式化。

## 4. 从攻击名称回到共同根因

尽管攻击名称繁多，跨主题可归纳为六类根因。**指令与数据没有强边界**意味着自然语言同时承担内容与控制，模型只能概率性判断优先级。**授权在错误层完成**意味着模型既决定动作又决定自己是否有权执行，而不是由独立策略根据用户、任务、资源和后果判定。**来源和身份在变换中丢失**意味着检索、OCR、摘要、压缩与跨代理转发后只剩纯文本，没有 provenance、tenant 或敏感性标签。
